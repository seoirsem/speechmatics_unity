# speechmatics_unity


Uses the websocket interface of Speechmatics SaaS. This is built on the NativeWebsocket package: [NWS_github](https://github.com/endel/NativeWebSocket)

Install via UPM (Unity Package Manager)
1. Open Unity
2. Open Package Manager Window
3. Click Add Package From Git URL
4. Enter URL: https://github.com/endel/NativeWebSocket.git
